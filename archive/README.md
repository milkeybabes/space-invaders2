# Historical / unused code and launchers

**Do not start the current Part II game from this folder.**

- `legacy_source/` holds old 1978 Part I entry points and early/unused modules that are **not imported** by current `part2_play.py`. Some relied on files at earlier root paths; preservation here does not claim these archived programs remain independently runnable.
- `old_launchers/` holds all original `.cmd` files from the mixed v25 package. Several execute `play.py` (the **1978 game**), not Part II. They are preserved only as a development record.

For **current Part II**, go to the project root and run `PLAY.cmd` or `python part2_play.py`.
