# Diagnostic utilities

Python tools: from the **project root** run `python -m tools.<script_name_without_py> [arguments]` so shared Part II modules resolve correctly.

MAME Lua scripts: see `tools/mame/`; pass their path to MAME's `-autoboot_script`. Their outputs are usually written to the current working directory. These tools are not required for ordinary gameplay.

For current command examples, see `docs/DEVELOPMENT.md`.
