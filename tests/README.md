# Part II regression tests

Run a test as a module **from the project root** (example):

```cmd
python -m tests.part2_v25_sound_test
python -m tests.part2_v24_final_features_test
python -m unittest tests.part2_headless_replay_test
```

The test files include early-stage cases retained for project history. The `part2_2player.inp` replay fixture and `sounds/` samples are in the project root. See `docs/DEVELOPMENT.md` for more examples.
